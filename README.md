# roseballvn.com — Rose FC Website

Website tĩnh responsive, sẵn sàng triển khai lên Vercel, Netlify hoặc Cloudflare Pages.

## Chạy thử
Mở `index.html` trực tiếp hoặc chạy server tĩnh: `python -m http.server 8080` trong thư mục này.

## Triển khai
- Vercel: import folder/repository, Framework Preset = Other, Output = root.
- Cloudflare Pages: upload folder, không cần build command.
- Netlify: kéo thả toàn bộ folder vào Netlify Drop.

## Domain
Sau khi mua `roseballvn.com`, trỏ DNS theo hướng dẫn của nền tảng hosting.

## Ghi chú
Form Join Us hiện dùng `mailto:` để không cần backend. Khi chạy production có thể thay bằng Formspree, Supabase hoặc API riêng.

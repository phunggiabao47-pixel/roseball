GÓI CẬP NHẬT MEDIA ROSE FC
=========================

File chính:
- media.html                : trang Media tổng
- media-newlife-friendship-cup-2025.html : album chi tiết
- styles.css                : style dùng cho cả 2 trang
- assets/                   : toàn bộ ảnh + clip

Cách dùng:
1. Chép 2 file HTML + styles.css + thư mục assets vào cùng cấp với website hiện tại.
2. Nếu website đã có media.html cũ, hãy thay bằng file media.html mới.
3. Có thể thêm link album mới trong Media về sau theo cùng cấu trúc.

Tone thiết kế:
- Ấm
- Gọn
- Sạch
- Đúng chất Rose
